# Project Template

A starter template for modern web applications built with HTML, CSS, TypeScript and Aurora CSS.

Designed to provide a clean, scalable and reusable foundation, this template includes a well-organized project structure and practical code examples that help speed up development while following consistent coding standards.

## Features

- HTML, CSS and TypeScript ready
- Aurora CSS preconfigured
- Clean and scalable folder structure
- Reusable component template
- Form component example
- Service templates (functional and class-based)
- Organized type definitions
- Utility folder for shared helper functions
- Easy to customize and extend

## Project Structure

```text
src/
├── assets/
├── components/
├── services/
├── styles/
├── types/
├── utils/
├── vendor/
└── main.ts
```

## Included Examples

The template contains commented examples to demonstrate common project patterns.

- Component template
- Form component
- Functional service
- Class-based service

These examples are intended as references and can be adapted or removed depending on the project's needs.

## Goals

- Encourage clean architecture
- Promote code reusability
- Keep projects organized and maintainable
- Provide a solid starting point for new applications
